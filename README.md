# Busca_carro

# Campo de pesquisa para buscar um carro de seu interesse
# Campo de pesquisa para verificar o preço a ser gasto pelo par de pneus, utilizando a pirelli como referencia
# Campo de pesquisa para veerificar a procedencia e histórico veicular

    O "Busca_Carro" foi desenvolvido com o objetivo de tornar prático e simples as pesquisa por carro,
pois ele apresenta um amplo catálogo de carros, utilizando a OLX como um site externo de pesquisa,
e para não ser necessario ficar procurando em outros lugares o APP ja fornece as ferramentas para
saber o histórico veicular em um unico lugar. Oferece tambem ligação com o site "Pirelli" para se 
ter noção do quanto seria gasto com um par de pneus, para determinado carro.
    O campo de pesquisa para buscar pelos veiculos é simples e pode ser utilizado de várias 
maneiras, se pode pesquisar o carro pela marca,nome,modelo e a "OLX" apresenta um catálogo amplo 
então suas pesquisa pode variar entre carros,vans e entre outros veiculos.
    O campo de pesquisa da "Pirelli" fornece pneus de vários tipos tambem,sendo necessario
passar as numerações especificas do pneu tais como, perfil, altura, diametro do aro e o indice de
velocidade. EX(265_65-R17).
    O campo de consultar placa utiliza o APP "AnyCar" que permite consultar placas de diversas 
formas, o app permite que consultar placas do modelo antigo e o estilo mercosul,apenas clicando no botão 
e pesquisar dentro do app.
